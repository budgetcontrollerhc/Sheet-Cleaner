Step 2b  —  Rows to delete

Build one or more conditions. A row is deleted if every column inside a single condition is blank or zero for that row. Add several conditions to cover different combinations — a row is dropped if it matches any one of them.

Step 2c  —  Insert new columns

Add a brand-new column with a fixed heading and, optionally, the same value in every row — a note, a status, a financial year, or just an empty column left for later. Position it afterwards in Step 2i (Reorder columns) below, alongside your existing columns.

Step 2d  —  Computed columns

Click columns below to drop them into the formula box, then combine them with +, −, *, /, and parentheses. Example: {Amount Spent} / {Amount Already Alloted by the High Court} * 100

Step 2e  —  Remove rows by condition

Build a set of conditions that must all be true (AND), then save it as one delete condition. Add more sets to cover different cases — a row is removed if it matches any saved set (OR). Example: (Amount Spent < 1000) AND (Percentage Expenditure ≥ 50).

Step 2f  —  Consolidate rows by identifier

Combine all rows that share the same identifier — a name, ID, account number and so on — into a single row, adding up (or otherwise combining) their values. This runs after unwanted rows have been removed and before computed columns, so formulas work on the combined figures.

Step 2g  —  Split output into sheets

Instead of one flat sheet, split the cleaned data into a separate tab per value of a column — e.g. one tab per district, department, or month.

Step 2h  —  Sort rows

Sort by one or more columns, in priority order — e.g. sort by District first, then by Amount Spent (highest first) to break ties within each district. If splitting into sheets, each tab keeps this same order.

Step 2i  —  Reorder columns

Move columns up or down to set their final left-to-right order in the output.
